## ظاهر و متن

- جمله‌های کوتاه‌تر و طبیعی‌تر؛ عنوان اصلی «کمتر تکرار. بیشتر خودت.».
- مرز پنل‌ها و بخش‌های تزئینی کم‌رنگ‌تر، گوشه‌های هماهنگ و سایه‌های سبک‌تر.
- خط دور ورودی‌ها، دکمه‌ها و focus عمداً واضح مانده است؛ محوشدن مرز تزئینی نباید تشخیص کنترل فرم را سخت کند.
- کارت‌ها سلسله‌مراتب جدا برای دسته، عنوان، قیمت و وضعیت دارند. تصویر فضای مستقل دارد؛ CTA جزئیات با کیبورد هم نمایان می‌شود.
- روی دسکتاپ، تصویر کارت اندکی با اشاره‌گر زاویه می‌گیرد و روشنایی ملایمی حرکت می‌کند؛ رویدادها با RAF تجمیع می‌شوند و در خروج اشاره‌گر پاک می‌شوند.

## پوستر واقعاً چه کاری می‌کند؟

این **صحنهٔ چندلایهٔ 2.5D** است، نه مدل سه‌بعدی قابل چرخش ۳۶۰ درجه یا فایل GLB.
از همان تصویر مفهومی AI، لباس با alpha از صحنه جدا شده و پس‌زمینه بازسازی شده است.
دو WebP محلی جمعاً حدود ۴۷ کیلوبایت‌اند و در زمان آماده‌سازی asset از base64 بازسازی می‌شوند.

- لباس مستقل از پس‌زمینه شناور می‌شود و چرخش بسیار کم در سه محور دارد.
- حرکت اشاره‌گر دسکتاپ، زاویهٔ دوربین و جابه‌جایی نسبی لایه‌ها را عوض می‌کند.
- حلقهٔ نور و حرکت هنگام اسکرول، عمق بصری را کامل می‌کنند؛ متن روی صحنه ثابت و خواناست.
- دکمهٔ توقف، انیمیشن را در همان وضعیت نگه می‌دارد؛ شروع مجدد از همان وضعیت ادامه پیدا می‌کند.
- خارج‌شدن پوستر از دید یا پنهان‌شدن تب، حرکت پیوسته را متوقف می‌کند.
- موبایل شناوری سبک‌تر دارد، اما دنبال‌کردن اشاره‌گر و tilt کارت روی لمس فعال نیست.
- reduced-motion بر انتخاب حرکت مقدم است؛ با کاهش حرکت، انیمیشن‌ها متوقف و وضعیت خنثی نمایش داده می‌شود.
- بدون بارگیری موفق GSAP، تصویر در وضعیت خنثی دیده می‌شود؛ نمایش کامل برنامهٔ Next و خرید همچنان به JavaScript نیاز دارد.

تصویر پوستر و تصویرهای استفاده‌شده در QA، کالای واقعی یا دادهٔ تازهٔ فروشگاه نیستند.
هیچ تصویر آزمایشی، قیمت ساختگی یا موجودی جدیدی وارد API/سید نشده است.

## بررسی‌ها

گزارش نهایی همین مرحله در توضیح PR ثبت می‌شود. تست‌های مرورگر با API آزمایشی‌اند، نه تایید دوبارهٔ اتصال Django یا پرداخت بانکی.
تست Redis بدون سرویس اجراشده skipped می‌شود. وضعیت CI باید جدا از موفقیت محلی بررسی شود.
بررسی تصویری شامل حالت فعال پوستر، زاویهٔ مخالف دوربین، کارت با تصویر تستی، موبایل، فرم خرید و نسخهٔ روشن/تیره است.

## اجرا بعد از دریافت تغییرات

وابستگی جدیدی اضافه نشده است. فرانت را متوقف و سپس از پوشهٔ `frontend` اجرا کنید:

```powershell
npm run prepare:assets
npm run dev:local
```

بک‌اند محلی را مثل قبل در ترمینال جدا روشن نگه دارید. اگر بسته‌ها نصب نیستند، ابتدا `npm ci` اجرا کنید.
