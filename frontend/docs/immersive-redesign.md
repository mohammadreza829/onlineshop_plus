# بازطراحی Immersive فروشگاه

## مبنا و محدوده

این نسخه از شاخهٔ `frontend/modern-redesign` در commit
`856b4c7b955498d137e4eb8ced89a165a2760576` ساخته شده است.
بازطراحی تازه در شاخهٔ `frontend/immersive-redesign` نگهداری می‌شود.
این تغییرات شامل ادغام PR شمارهٔ ۱۰ (`fix/local-demo-integration`) نیست.
هیچ فایل بک‌اند، تنظیم پرداخت یا migration در این بازطراحی تغییر نکرده است.

## چه چیزی تغییر کرده؟

- سیستم بصری تازه با زمینهٔ استخوانی، سبز تیره و رنگ لیمویی؛ حالت تیره بر اساس تنظیم سیستم.
- صفحهٔ اصلی سینمایی، تایپوگرافی بزرگ فارسی، تصویر محلی WebP و نوار متحرک تایپوگرافی.
- هدر، منوی موبایل، کشوی سبد و فوتر جدید؛ حفظ لینک‌ها، دسترس‌پذیری کیبورد و رفتارهای واقعی قبلی.
- ظاهر یکپارچهٔ کاتالوگ، فیلتر، کارت محصول، جزئیات و انتخاب تنوع، سبد، ورود، آدرس‌ها، سفارش‌ها، حساب و نتیجهٔ پرداخت.
- قیمت قبلی و درصد تخفیف کارت فقط از فیلدهای واقعی API نمایش داده می‌شوند؛ آمار فروش، نظر، موجودی یا محصول ساختگی به برنامه اضافه نشده است.
- فونت محلی، RTL، `bdi` برای محتوای ترکیبی و چیدمان واکنش‌گرا حفظ شده‌اند.

یک ناهماهنگی hydration در صفحهٔ اصلی نیز اصلاح شد: کش دسته‌های هدر ممکن بود زودتر از بخش streamed خانه پر شود. نمایش اولین رندر اکنون با snapshot سرور یکسان می‌ماند و بعد از hydration دادهٔ زنده را نمایش می‌دهد، بدون حذف SSR یا تکرار درخواست داده.

## منطق انیمیشن

`components/motion/experience.tsx` یک لایهٔ progressive enhancement است:

- GSAP و ScrollTrigger به‌صورت lazy بارگذاری می‌شوند: ورود مرحله‌ای، reveal هنگام اسکرول، حرکت عمقی تصویر و دکمهٔ مغناطیسی روی اشاره‌گر دقیق دسکتاپ.
- Lenis فقط در خانه و مسیرهای محصولات، با حداقل عرض ۱۰۲۴ و اشاره‌گر دقیق، فعال است.
- سبد، ورود، حساب و مسیرهای مالی اسکرول native دارند. موبایل و reduced-motion نیز native هستند.
- یک ticker مشترک GSAP/Lenis استفاده می‌شود؛ در تغییر مسیر یا تنظیم حرکتی، ticker، listener و instance قبلی پاک می‌شوند.
- بازشدن دیالوگ Radix اسکرول Lenis را متوقف می‌کند؛ بسته‌شدن، اسکرول را برمی‌گرداند. خود دیالوگ از اسکرول نرم مستثنا است.
- تغییر زندهٔ reduced-motion رعایت می‌شود. در خطای import انیمیشن، محتوا و خرید همچنان قابل استفاده هستند. نمایش کامل برنامهٔ Next و جریان تعاملی خرید همچنان به JavaScript نیاز دارد؛ در حالت خاموش، پیام noscript این محدودیت را روشن توضیح می‌دهد.
- نوار تایپوگرافی و hoverها CSS هستند؛ در reduced-motion متوقف می‌شوند.

وابستگی جدیدی اضافه نشده است؛ GSAP و Lenis از lockfile همین نسخه استفاده می‌کنند.
React Bits یا کتابخانهٔ دیگری صرفاً برای زیادشدن نام وابستگی‌ها اضافه نشده است.

## تصویر

`assets/immersive-hero.webp.b64` خروجی تصویری تولیدشده با هوش مصنوعی، مخصوص این بازطراحی است؛ تصویر محصول واقعی نیست.
این موضوع در alt و توضیح قابل مشاهدهٔ صفحه درج شده است.
`npm ci`/`prepare:assets` آن را به `public/editorial/immersive.webp` تبدیل می‌کند.
نمایش آن نیازی به سرویس تصویر بیرونی ندارد. تصویر قبلی حذف نشده است.

## اجرای محلی

پس از دریافت این شاخه، اجرای بک‌اند همان روش قبلی پروژه است.
در ترمینال جدا:

```powershell
cd frontend
npm ci
npm run dev:local
```

نصب بسته‌ها نیازمند دسترسی به رجیستری npm است. `npm ci` را در هر بار اجرای سایت تکرار نکنید.
تنظیمات `.env.local` شخصی است و نباید commit شود.
برای بررسی کد و ساخت:

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```

تست مرورگر به سرور فرانتِ از قبل اجراشده نیاز دارد؛ مقدار پیش‌فرض پورت تست ۳۱۰۰ است.
`tests/e2e/storefront.spec.ts` یک سناریوی واقعی Django و چند سناریوی mock دارد؛ این دو را یکی ندانید.
سناریوی واقعی به harness و دیتابیس ایزوله نیاز دارد و پرداخت بانکی واقعی انجام نمی‌دهد.

## وضعیت بررسی این بازطراحی

نتیجهٔ نهایی بررسی‌ها در توضیح PR ثبت می‌شود.
آزمون‌های `immersive-motion.test.ts` سیاست فعال‌سازی حرکت را بررسی می‌کنند.
`immersive.spec.ts` مسیرهای اصلی را در روشن/تیره و عرض‌های ۱۴۴۰/۳۹۰ با پاسخ‌های API تستی بررسی می‌کند.
تست دسترس‌پذیری با reduced-motion اجرا می‌شود تا اندازه‌گیری رنگ در میانهٔ fade انجام نشود؛ تست مجزای انیمیشن با حرکت فعال، cleanup، قفل دیالوگ و تغییر زندهٔ تنظیم را بررسی می‌کند.
تست‌های مرورگری mock، تایید اتصال کامل بک‌اند یا پرداخت واقعی نیستند.

این نسخه بازطراحی فرانت است، نه رفع دوبارهٔ همهٔ مسائل بک‌اند یا تایید امنیت انتشار عمومی.
